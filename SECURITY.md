# Security policy

## Reporting

Please report suspected vulnerabilities privately through GitHub's security-advisory interface when available. Do not include real credentials, private repository content, or exploit data in a public issue.

For documentation-only contact examples, use `security@example.invalid`; it is not a monitored mailbox.

## Supported version

| Version | Supported |
|---|---:|
| `0.1.x` | Yes |
| older | No |

## Important limitation

GAWSL is a heuristic static analyzer. A clean report does not prove that a workflow, action, agent, dependency, runner, cloud role, or external service is secure.
