# Changelog

## 0.1.0 — 2026-08-30

### Added

- deterministic heuristic analyzer for GitHub Actions and agentic workflow risks;
- 22 rules covering permissions, pinning, injection, privileged events, runners, artifacts, OIDC, containers, prompt injection, model output, direct mutation, secrets, concurrency, and approvals;
- ten vulnerable/hardened workflow pairs stored outside the active workflow directory;
- text, JSON, and SARIF output;
- expiring path- and fingerprint-scoped waivers;
- CLI commands for scanning, rule inspection, lab verification, and config initialization;
- Python 3.11–3.13 test matrix, fixture safety gate, privacy audit, link audit, and reproducible wheel check;
- English and Chinese documentation.
